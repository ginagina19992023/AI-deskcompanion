# 语音聊天功能使用指南

这份指南帮助您启用和使用 AI Desktop Companion 中的语音和聊天功能。您可以让宠物说话、用麦克风聊天、收听语音回复。

---

## 快速开始

### 1. 启用语音功能

1. 右键点击宠物窗口，选择 **设置**
2. 在设置窗口中找到 **🎤 语音设置** 部分
3. 勾选 **启用语音输出与输入**
4. 点击**确定**保存设置

此时宠物就能说话了，您也可以按 **F9** 用麦克风讲话。

### 2. 启用聊天功能

1. 在设置窗口中找到 **💬 聊天设置** 部分
2. 勾选 **启用聊天**
3. 根据您的需求选择配置：
   - **基础文字聊天**：直接点发送即可
   - **聊天时启用语音回复**：宠物会用语音读出回复（可选）
4. 点击**确定**保存设置

现在您可以用 **Alt+A** 快捷键或点工具栏打开聊天窗口。

## 详细功能说明

### 语音设置（🎤 Voice Settings）

在设置中的"语音设置"部分，您可以调整：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| **启用语音输出与输入** | 启用宠物说话和语音识别 | 禁用 |
| **语音输出音量** | 调整宠物说话的音量（0-1.0） | 1.0 |
| **语速** | 调整宠物说话的速度（0.5-2.0） | 1.0 |
| **音高** | 调整宠物说话的音高（0.5-2.0） | 1.0 |
| **推送通话快捷键** | 设置语音输入的快捷键 | F9 |

**提示：** 调整音量、语速、音高后立即生效，无需重启应用。

### 聊天设置（💬 Chat Settings）

在设置中的"聊天设置"部分，您可以配置：

| 设置项 | 说明 | 选项 |
|--------|------|------|
| **启用聊天** | 启用聊天功能 | 开/关 |
| **聊天时启用语音回复** | 宠物用语音读出聊天回复 | 开/关 |
| **聊天模型提供商** | 选择 AI 模型提供商 | Ollama / OpenAI 兼容服务 |
| **Ollama 地址** | 本地 Ollama 服务地址 | http://localhost:11434 |
| **模型名称** | 要使用的 AI 模型名称 | gemma4:12b（默认） |

**提示：** 
- 使用 Ollama（本地）无需网络和 API 密钥
- OpenAI 兼容服务适合使用 LM Studio 等服务

## 使用方式

### 文字聊天

1. **打开聊天窗口**
   - 按 **Alt+A** 快捷键，或
   - 点宠物窗口工具栏的聊天按钮

2. **输入消息**
   - 在输入框输入文字
   - 点"发送"按钮或按 **Enter** 键

3. **查看回复**
   - 宠物的回复会显示在气泡中
   - 如果启用了"聊天时启用语音回复"，同时会听到宠物说话

**键盘快捷键：**
- **Alt+A**：打开/关闭聊天窗口
- **Enter**：发送消息
- **Escape**：关闭聊天窗口

### 语音聊天

#### 方式 1：按住快捷键说话

1. 打开聊天窗口（Alt+A）
2. **按住 F9 键** 开始说话
3. 说话时窗口中会显示 **"正在聆听..."** 状态
4. **松开 F9 键** 系统开始识别语音
5. 识别结果自动填入聊天输入框
6. 按 **Enter** 发送，或继续编辑后再发送

#### 方式 2：点击麦克风按钮

1. 打开聊天窗口（Alt+A）
2. 点聊天输入框旁的 **🎤 按钮**
3. **按住鼠标** 开始说话
4. 松开鼠标停止识别
5. 识别结果填入输入框
6. 按 **Enter** 发送

**提示：**
- 说话要清晰，避免背景噪音
- 一次可以说多句话（最多约 30 秒）
- 识别失败时检查麦克风权限和驱动

### 情感气泡的语音播放

当您启用了语音功能后，点击任何宠物的表情气泡都会：
- 用宠物的声音朗读气泡文字
- 如果聊天中，同时使用聊天语音回复的设置

## 常见问题（FAQ）

### 声音/音频相关

**Q: 为什么没有听到宠物说话？**

A: 请检查以下几点：
1. ✓ 确认"启用语音输出与输入"已勾选
2. ✓ 检查语音输出音量是否为 0（调整滑块）
3. ✓ 检查系统音量是否静音（右下角音量图标）
4. ✓ 检查浏览器/应用的音量是否被静音
5. ✓ 确认您的设备有音频设备（扬声器/耳机）
6. ✓ 尝试在聊天中输入一条消息以触发语音输出

**Q: 宠物说话的声音太快/太慢怎么办？**

A: 在语音设置中调整**语速**滑块：
- 向左拖动：变慢（最低 0.5x）
- 向右拖动：变快（最高 2.0x）
- 默认 1.0 是正常速度

**Q: 宠物说话的音高听起来怪怪的？**

A: 调整**音高**滑块以改变语调：
- 向左拖动：变低沉
- 向右拖动：变尖锐
- 默认 1.0 是自然音高

---

### 麦克风/语音识别相关

**Q: 为什么语音识别不工作？**

A: 语音识别有以下限制：
- ⚠️ **仅支持 Windows**（macOS 和 Linux 不支持）
- ⚠️ 需要 Windows 自带的 SAPI（Speech API）
- 需要允许应用使用麦克风权限

检查清单：
1. ✓ 确认操作系统是 Windows
2. ✓ 在 Windows 设置中允许应用访问麦克风
3. ✓ 麦克风硬件正常工作（测试其他应用的录音）
4. ✓ 尝试重启应用

**Q: 语音识别总是失败/无法识别我的声音？**

A: 请尝试以下方式改善识别：
- 使用靠近麦克风 10-15 厘米处说话
- 减少背景噪音（关闭风扇、音乐等）
- 说话清晰，避免口音过重
- 说完后等待 1 秒让系统处理
- 如果多次失败，检查麦克风是否工作（在 Windows 音频设置中测试）

**Q: 如何更改语音识别的快捷键？**

A: 在语音设置中修改"推送通话快捷键"字段：
1. 点击输入框
2. 输入键名（如 `F10`、`V` 等）
3. 点确定保存

支持的键名示例：`F1`-`F12`、`A`-`Z`、`0`-`9` 等。

---

### 聊天功能相关

**Q: 为什么聊天没有回复？**

A: 请检查以下设置：
1. ✓ 确认"启用聊天"已勾选
2. ✓ 检查模型提供商配置是否正确
3. ✓ 如果使用 Ollama：
   - 确保 Ollama 已启动（运行 `ollama serve`）
   - 检查地址是否正确（默认 `http://localhost:11434`）
   - 检查模型是否已下载（运行 `ollama list` 查看）
   - 如果没有模型，运行 `ollama pull gemma4:12b` 下载
4. ✓ 如果使用 OpenAI 兼容服务：
   - 检查网络连接是否正常
   - 验证服务地址和 API 密钥是否正确

**Q: 聊天回复太慢了？**

A: 这取决于您的模型和硬件：
- 较小的模型（如 mistral:7b）会更快
- 较大的模型（如 llama2:70b）会较慢
- 网络延迟（OpenAI 兼容服务）
- 建议尝试不同的模型以找到速度和质量的平衡

**Q: 如何更改使用的 AI 模型？**

A: 在聊天设置中修改"模型名称"字段：
1. 查看可用模型列表：
   - **Ollama**：运行 `ollama list`
   - **LM Studio**：在软件中查看可用模型
2. 在设置中输入模型名称（如 `mistral:7b`、`llama2`）
3. 点确定保存

**Q: 聊天时宠物没有说话？**

A: 检查以下设置：
1. ✓ "启用语音输出与输入"已勾选
2. ✓ "聊天时启用语音回复"已勾选
3. ✓ 音量不为 0
4. ✓ 系统音量已打开

---

### 设置和配置相关

**Q: 设置保存后下次启动丢失了？**

A: 设置应该会自动保存到 `config.json` 文件中。如果丢失：
1. 检查应用是否正常关闭（不是强制关闭）
2. 检查 `config.json` 文件是否存在和可写
3. 尝试再次设置并确认看到"保存"确认
4. 重启应用验证设置是否保持

**Q: 如何重置所有语音和聊天设置到默认值？**

A: 您可以：
1. **部分重置**：在设置窗口手动调整各项回到默认值
2. **完全重置**：
   - 关闭应用
   - 编辑 `config.json` 文件
   - 删除 `voice` 和 `chat` 部分
   - 保存文件并重启应用

**Q: 设置文件在哪里？**

A: 设置存储在应用目录下的 `config.json` 文件中。
