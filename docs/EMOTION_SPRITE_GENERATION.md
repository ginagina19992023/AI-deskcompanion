# 情绪反应动作 —— 待生成美术素材规格

现在 `config.default.json` 里的 `emotionRows`（happy/sad/angry/surprised → 动作行号）先借用了每只宠物**已有**的行凑数（比如塞巴斯蒂安的 surprised 借用"戴礼帽"、夏尔的 sad 借用"下棋思考"）。这份文档是给 GPT/图像生成工具的**生成规格**，用来产出**专属的**情绪动作行，之后替换掉这些借用的占位映射。

分两个阶段：**第一阶段（本文档范围）** 只生成美术素材，放进暂存目录；**第二阶段**（素材到位后，回来找我）再把新行合并进正式图集文件、改 `atlas.js`/`config.default.json`，这一步不需要你自己动手。

## 技术规格（硬性约束，来自 `src/atlas.js`）

- **画布尺寸**：每帧 **192 × 208 px**，透明背景（PNG，保留 alpha 通道，生成阶段不要用 webp——有损压缩会糊边）。
- **每行帧数**：统一 **6 帧**（跟现有"端茶托盘/闭眼鞠躬/持餐刀/栖息挂枝"等短动作行一致的帧预算）。
- **角色比例/画风必须跟该宠物现有素材保持一致**——同一体型、同一服装配色、同一线条粗细。生成时请参考该宠物现有图集里的既有帧作为风格参照（见下方每个角色的"参照行"）。
- **构图基线**：角色应站在格子底部附近（脚部/底座对齐现有帧的落地线），跟现有帧的"重心高度"保持一致，不要飘在格子中间或贴顶。
- 6帧应该构成一个**短促的、可循环或可定格在最后一帧的姿势演变**（第0帧是起始姿态，逐帧过渡到情绪的顶点姿态），参考现有"闭眼鞠躬""端茶托盘"这类行的节奏感。

## 生成产物的命名与存放（第一阶段：暂存，不直接进 `assets/pets/`）

不要直接覆盖或追加到现有的 `assets/pets/sebastian-raven.webp` / `assets/pets/ciel-young-master.webp`——那两个是正式图集文件，合并是第二阶段的机械步骤，由我在拿到素材后统一处理（校验旧行像素级不变、拼接新行、重新编码webp）。

**生成阶段请把每一帧存成单独的PNG**，放进这个目录结构（目录不存在就新建）：

```
assets/pets-staging/
├── sebastian-raven/
│   ├── emotion-happy/
│   │   ├── frame-00.png
│   │   ├── frame-01.png
│   │   ├── frame-02.png
│   │   ├── frame-03.png
│   │   ├── frame-04.png
│   │   └── frame-05.png
│   ├── emotion-sad/
│   │   └── frame-00.png ... frame-05.png
│   ├── emotion-angry/
│   │   └── frame-00.png ... frame-05.png
│   └── emotion-surprised/
│       └── frame-00.png ... frame-05.png
└── ciel-young-master/
    ├── emotion-happy/
    │   └── frame-00.png ... frame-05.png
    ├── emotion-sad/
    │   └── frame-00.png ... frame-05.png
    ├── emotion-angry/
    │   └── frame-00.png ... frame-05.png
    └── emotion-surprised/
        └── frame-00.png ... frame-05.png
```

命名规则：`assets/pets-staging/<pet-id>/emotion-<emotion名>/frame-<两位数字从00开始>.png`

- `<pet-id>` 固定用 `sebastian-raven` 或 `ciel-young-master`（跟 `config.default.json` 里的 `pets[].id` 一致）
- `<emotion名>` 固定用 `happy`/`sad`/`angry`/`surprised`（跟 `emotionRows` 的 key 一致，方便合并脚本直接按名字对应）
- 每个情绪目录正好6个文件，`frame-00.png` 到 `frame-05.png`
