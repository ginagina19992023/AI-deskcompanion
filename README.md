# 黑执事桌面宠物

Windows 桌面宠物：头随鼠标转、无人操作时自己在桌面上活动。内置塞巴斯蒂安与夏尔两只，行为按各自性格分别调过。

除基础动画外，还包含屏幕边缘自适应圆环、桌面审批卡、整窗透明控制、待办/番茄钟，以及根据当前系统音频强弱随机触发的角色化音乐点评。

AI 状态显示支持 Claude Code hooks、Codex 本地实时工具事件，以及 DeepSeek、Kimi 和其他 OpenAI-compatible agent 的通用本地上报接口。接入格式与示例见 [`docs/AI_ACTIVITY_INTEGRATION.md`](docs/AI_ACTIVITY_INTEGRATION.md)。

Claude 的任务状态与上下文窗口圆环所需 hook 已随仓库收录在 [`tools/claude-hooks/`](tools/claude-hooks/)；当前机器已经安装。圆环默认开启，并显示所有新鲜会话中上下文占用最高的一项，因此不会被另一个 AI 的状态气泡覆盖。

```bash
npm install
npm start
```

双击根目录的 `INSTALL-DESKTOP-SHORTCUT.bat` 运行一次，会在桌面生成「AI Desk Companion」快捷方式。它指向隐藏启动器 `tools/start-desktop-pet.vbs`，在后台跑 `npm start`、不弹黑框命令行窗口，以后双击桌面图标就能直接干净地打开宠物。

仓库内的 `config.default.json` 是可直接运行的安全默认配置。首次在控制面板保存设置时会生成仅供本机使用的 `config.json`；它和 `data/` 下的截图、聊天、待办、令牌及运行状态都不会进入 Git。

需要屏幕观察、工作监督或角色对话时，请在控制面板中主动开启并配置本地 Ollama 或兼容接口。发布默认值不会自动截图，也不会自动向模型发送屏幕或对话内容。

托盘图标 →「切换宠物」「暂停闲逛」「召回到光标旁」「退出」。

## 两只宠物的差异

行为不是同一套参数换张图，是按角色性格分开配的（`config.json` 里每只宠物的 `gaze` 与 `profile`）。

| | 塞巴斯蒂安 | 夏尔 |
|---|---|---|
| 性格依据 | ISTJ 式高效、极度注重细节；「猫一般的迂腐、掠食、爱玩」；以超然兴味观察人类；忠于职责 | INTJ / 5w6 观察者；高傲、不耐烦；视他人为次等；身体孱弱、厌恶消耗体力 |
| 目光跟随 | **持续盯着你**，永不移开（`attentionMs: 0`） | **瞥一眼就移开**（2.6s 后失去兴趣），你大幅移动才重新赢得注意 |
| 反应速度 | 快（`tau 0.10`） | 慢而勉强（`tau 0.22`） |
| 注意范围 | 900px，隔很远就注意到 | 520px，只有靠近才理你 |
| 闲逛倾向 | 45%，移动快（115 px/s） | 18%，移动慢（62 px/s） |
| 休息倾向 | 10% | 32% |
| 出手频率 | 7–16s | 12–26s |

## 转头是怎么实现的：两种模式

图集第 9/10 行按契约命名为 `look-000-to-157.5` / `look-180-to-337.5`，合起来是 16 帧、每帧 22.5° 的一圈。但**两只宠物的这两行实际内容并不一样**，所以有两种模式。

### `frames` 模式（塞巴斯蒂安）

行 9/10 是**真的转头素材**。实测「脸相对头部轮廓的横向偏移」：

- k=4（yaw +90°，光标在右）→ 偏移 **+21.7px**，露右侧脸
- k=0（正前）→ 偏移 −0.7px
- k=12（yaw −90°，光标在左）→ 偏移 **−21.7px**，露左侧脸
- k=7 附近皮肤像素跌到 246（正面时 3101）＝ 完全背对

所以直接把光标方位角映射到帧号即可，美术干净、无形变。

### `lean` 模式（夏尔）

夏尔的行 9/10 **没有方向性视线信息**，尽管他的 README 写着「16 个方向的头部、视线微动」、`validation.json` 也把这两行命名为 `look-*`。实测：

- 脸相对头部的偏移全程只在 **+6.5 ~ +8.4px** 之间（波动 1.9px），对比塞巴的 43px 跨度
- 虹膜相对头部的偏移只有 **±0.8px**，噪声级别
- 真正在动的是**整个头部横向平移约 10px 再移回来** —— 是摇摆循环，不是转头

用这些帧做跟随会得到一个方向错误且几乎看不出来的效果。因此夏尔改用整体**微倾 + 向光标微移**（最多 7px）来表示「他注意到你了」——配合他 2.6 秒就移开视线的设定，反而很贴人设。

如果以后重新生成夏尔的行 9/10（真正让脸相对头部转动），把 `config.json` 里他的 `gaze.mode` 改回 `"frames"` 即可，其余不用动。

## 对 Codex 桌宠的反应

塞巴斯蒂安能看见 Codex/ChatGPT 应用自己画的那只桌宠（目前是夏尔），并且：

1. **少爷优先于鼠标**：夏尔进入 700px 内时，塞巴不再跟随光标，改为看向少爷。
2. **行礼**：夏尔进入 420px 时播一次脱帽致意（行 3），有 25s 冷却，且只在「进入范围」的那一刻触发，不会一直重复。

**完全只读**。只向 Windows 查询那个窗口的矩形，不接触、不注入、不修改 Codex 进程，和 `codex-mouse-follow-patch` 那类补丁没有任何关系，风险为零。

识别方式是**扩展窗口样式**而不是标题——`WS_EX_TRANSPARENT (0x20) + WS_EX_TOOLWINDOW (0x80)`，即点击穿透、不进任务栏的覆盖层。这样 Codex 改标题也不影响。找不到就安静回落到普通行为，不会崩。

实现是 `tools/watch-companion.ps1` 常驻子进程，每 200ms 打印一行 JSON，`src/companion-watcher.js` 读它的 stdout。零原生依赖。

**已知精度限制**：覆盖层窗口比立绘大得多（实测 613×602 的窗口里装 168×261 的立绘），夏尔可能在窗口内移动，所以定位精度约几十像素。做「看向他」「行礼」够用；做精确肢体接触不行。锚点比例在 `config.json` 的 `companion.anchor`，需要时可调。

关掉的话把 `config.json` 里 `companion.enabled` 设为 `false`。

## 结构

纯函数模块不碰 DOM 与 Electron，可直接 `node --test`：

- `src/atlas.js` — 图集几何与帧矩形
- `src/head.js` — 方位角→帧号、迟滞、`createGaze` 注意力模型
- `src/brain.js` — 行为状态机，性格档案驱动
- `src/companion.js` — 感知另一只桌宠的**纯逻辑**（解析、锚点、行礼触发）
- `src/companion-watcher.js` — 只有主进程能加载（用了 `node:child_process`）
- `src/renderer.js` — canvas 绘制、crossfade、命中检测
- `src/main.js` — 窗口、光标轮询、位移、托盘

> `companion.js` 与 `companion-watcher.js` 必须分开：渲染进程 `nodeIntegration: false`，模块图里只要混进一个 `node:` import，整个渲染进程就会静默死掉、宠物直接不画了，从外面极难诊断。有一条单测专门守这条规则。

```bash
npm test          # 178+ 个单测
npm run preview   # 起静态服务，再开 http://127.0.0.1:8731/tools/preview.html
npm run sync-atlas # 刷新 preview 用的图集副本
```

`tools/preview.html` 有 yaw 滑块和全 11 行逐帧预览，用来核对转头方向有没有左右反。

## 已知实现细节

- **软件合成**：`disableHardwareAcceleration()`。透明无边框窗口在部分 Windows 驱动上会让渲染进程直接崩溃；192×208 的精灵用软件合成开销可忽略。要试硬件加速就把 `config.json` 的 `disableHardwareAcceleration` 设成 `false`。
- **高 DPI**：canvas 按 `devicePixelRatio` 开背板（本机 1.5×），否则深红描线会糊。命中检测的坐标也按 dpr 换算。
- **点击穿透**：只有光标压在非透明像素上时窗口才可交互，其余时间点击直达桌面。
- **crossfade**：任何状态切换都走 140ms 淡入淡出。执事↔黑鸦没有变身帧，待机行与转头行的姿态也对不上（实测整帧平均差 23.6），统一用它兜住。
- **Electron 二进制**：本机从 GitHub 拉取失败，用 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 装的。重装依赖时可能要再加这个环境变量。
